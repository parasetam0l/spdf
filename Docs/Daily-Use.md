# Daily-use guide

## Create, open and read

Choose **New PDF** in the Welcome window or File menu (Command-N) to create an untitled blank PDF. **Add Text** starts active: click the page and type directly on it. Return starts another line; **Done** or Command-Return adds the real page content. Escape cancels the pending text. After Done, Edit PDF becomes active so you can select and move the new text. Save (Command-S) names and writes the new document. Settings (Command-comma) selects A4 or US Letter, portrait or landscape, and the default page layout.

Open a PDF with File → Open or Finder. Use the View menu for fit-page, fit-width, actual size and page navigation. Locked documents remain restricted until you use Tools → Security → Unlock Document. Sidebar panels share the resizable document workspace; switching panels preserves the window size.

Hold Command and scroll up over the document to zoom in, or scroll down to zoom out. Zoom follows the page point under the pointer and also works while editing text. Scroll without Command to move through the document normally.

Use Command-F to open Find. Enter a phrase and press Return to search, then use Previous Match or Next Match to move through the results. Editing the phrase shows “Return to search” until you submit the new query.

## Edit text and images

Click **Edit PDF** in the command bar (or Control-Command-2). Click a supported text block to select it; dragging the block moves it. Double-click the selected text or choose **Edit Text** in the Text properties panel to place a caret and type directly on the page. While typing, drag the blue move grip to reposition the block. Arrow keys on the selected block or grip move one point, or ten with Shift.

The Text properties panel shows the source font and lets you change size, color and position in page points. Its six alignment buttons position the text box against the page edges or center; they do not change paragraph justification. Supported text also offers Helvetica, Times and Courier, with Bold (Command-B) and Italic (Command-I). Imported embedded fonts keep their existing glyphs for text, size and color edits; choose one of the standard families explicitly to change their family or traits. Select characters while typing to format just those characters. With no character selection, the controls set the style for subsequent typing; with the whole box selected, they format the entire box. Mixed selections are identified in the panel. These changes appear on the page before you commit. Use the Text properties button beside Find to show or hide the panel; compact windows open it as a popover. Page navigation and zoom stay in the bottom bar. The left navigation tabs switch between pages, comments and forms; its More menu opens the other panels.

Supported multi-line paragraphs select as one object. Type to wrap within the paragraph width; drag the handle on its right edge or change **Width** in Text properties to reflow the words. Return inserts a line break in a paragraph. Saved paragraph lines use the native editor’s actual positions. sPDF also retains its authored box width, soft wrapping and explicit paragraph breaks when reopening, including mixed standard and supported embedded-font spans. Formatting has native Undo/Redo while typing; the complete committed edit is one document Undo. Nearby short labels and uncertain paragraph boundaries remain separate blocks. Visible bullet markers and simple numbered prefixes keep adjacent list items separate, while supported wrapped body lines remain one paragraph. Existing bullet/number glyphs are preserved; this does not provide automatic numbering, list indentation or movement of separately painted markers.

**Done** or Command-Return commits the selected block. Return commits while typing in a single existing line. Escape discards its pending changes. Cut, Copy and Paste use the standard Command-X/C/V shortcuts while typing. Pasted text adopts the current text style. Save commits pending text before writing; closing with changed text prompts to save. Command-Z first undoes typing while the caret is active; committed text and movement use document Undo/Redo. Zooming, scrolling and resizing keep the editor attached to the page.

Paragraph editing supports regular left-aligned horizontal text on unrotated pages when the native wrapping matches the source. It follows separate columns and preserves the source baseline spacing, mixed styles, supported embedded TrueType fonts (including horizontal Identity-H subsets), character/word spacing and bounded text-array adjustments. Existing font programs and their glyph codes are reused. Visible word-sized positioning gaps can become editable spaces while retaining the original glyph positions; ambiguous letter tracking stays unchanged. A subset can only supply the glyphs it contains; unavailable characters are refused before insertion, and another font can be chosen explicitly. The imported-font path currently covers Latin, Greek and Cyrillic without combining or contextual shaping. Supported embedded-font text inside a single rectangular clipping area can also be edited when all source glyphs are visible. Its original boundary stays fixed and appears as a dashed outline; text that crosses it shows an inline warning and must be brought back inside before committing. Different clipping areas are kept separate. Arbitrary clipping paths, partly hidden source text, vertical/bidirectional text, complex scripts, CFF fonts, rotated/skewed or nonuniformly transformed text and uncertain paragraph boundaries remain restricted. Uniform source scaling is converted to page points. Paragraphs do not flow onto other pages or move surrounding objects. The standard font controls refuse characters they cannot represent; they do not embed arbitrary system fonts. Reflow Paragraph remains available within its separate font and region limits. Image-only scans need OCR before text can be selected; complex fonts may remain read-only.

Switch back with **Select** (Control-Command-1). In Select mode, dragging a graphic only selects it and never dirties the document.

Click **Images** (Control-Command-4), then **Insert Image…** to place a raster image in the center of the current page. PNG transparency is retained as a soft mask, so transparent pixels reveal the page content beneath them; it is not flattened over white. Drag an inserted image to move it; drag its handles to resize it, holding Shift on a corner to keep proportions. The selected image content is previewed at the proposed position and size, and Escape restores the original. Shift-click or drag a selection rectangle to select several added objects, which resize together with their spacing preserved. Image properties offers X/Y, width/height with **Keep proportions**, page alignment, Rotate 90° and Delete Selection. Numeric image changes apply on Return or when leaving the field; Save commits the active numeric field before writing. With the image selected on the canvas, arrow keys move one point, or ten with Shift. Delete removes added objects in one undoable edit. Escape cancels an active drag; otherwise it clears the selection. Move, resize and Delete are enabled only in Images mode. Use the Image properties button beside Find to show the panel or its compact-window popover.

Supported images already present in the PDF can also be selected and dragged or resized on the canvas when their draw has a direct, axis-aligned placement and any enclosing page scale is axis aligned. The page transform and clipping are preserved. Rotated or skewed placements, and images nested in reusable form objects, refuse canvas movement with a specific reason; supported existing images can still use the image context menu to rotate, scale, or replace them. Shared image objects and unsupported content produce explicit choices or refusal reasons.

## Annotate, fill forms, and organize pages

Click **Comments** for Highlight, Add Note and Draw controls. The comments sidebar supports navigation, replies, and review state. The Edit and Annotate menus retain advanced annotation commands and drawn signatures. Common form fields can be filled in the page or Forms sidebar; press Return to commit a text value. Form properties and authoring commands are available in the Form menu.

Click **Pages** for Organize Pages, Insert Blank Page and Rotate Right. The Page menu includes importing, reordering, rotation and deletion. Operations that would damage references are refused or require a supported resolution.

## OCR and exports

OCR in the Annotate menu uses on-device recognition to add searchable text to scans. Tools → Review Tables shows detected cells before CSV or XLSX export. File → Export groups text, page images, HTML, DOCX, table, attachment and printed PDF exports; [Exports](Exports.md) explains their fidelity limits. Tools groups comparison, optimization, repair, security and print-production commands.

## Save and recover

Save writes a verified result and preserves original bytes for an untouched document. Edited saves use an incremental revision where eligible, with a verified rewrite when necessary. Protected documents retain their protection policy.

Redaction and sanitization require a separate derivative that removes old revisions. Do not treat a covering annotation or ordinary Save as secure removal. Preserve a backup before an unfamiliar or destructive transformation.

Recovery data stays local. Use sPDF Editor → Check for Updates for a manual release check. Settings contains the automatic-check preference. See [Updates](Updates.md) for installation, unsaved-work handling and guidance for older versions.
