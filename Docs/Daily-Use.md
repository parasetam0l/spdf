# Daily-use guide

## Create, open and read

Choose **New PDF** in the Welcome window or File menu (Command-N) to create an untitled blank PDF. **Add Text** starts active: click the page and type directly on it. Return starts another line; **Done** or Command-Return adds the real page content. Escape cancels the pending text. After Done, Edit PDF becomes active so you can select and move the new text. Save (Command-S) names and writes the new document. Settings (Command-comma) selects A4 or US Letter, portrait or landscape, and the default page layout.

Open a PDF with File → Open or Finder. Use the View menu for fit-page, fit-width, actual size and page navigation. Locked documents remain restricted until you use Tools → Security → Unlock Document. Sidebar panels share the resizable document workspace; switching panels preserves the window size.

Hold Command and scroll up over the document to zoom in, or scroll down to zoom out. Zoom follows the page point under the pointer and also works while editing text. Scroll without Command to move through the document normally.

Use Command-F to open Find. Enter a phrase and press Return to search, then use Previous Match or Next Match to move through the results. Editing the phrase shows “Return to search” until you submit the new query.

## Edit text and images

Click **Edit PDF** in the command bar (or Control-Command-2). Click a supported text block to select it; dragging the block moves it. Double-click the selected text or choose **Edit Text** in the Text properties panel to place a caret and type directly on the page. While typing, drag the blue move grip to reposition the block. Arrow keys on the selected block or grip move one point, or ten with Shift.

The Text properties panel shows the source font and lets you change size, color and position in page points. Its six alignment buttons position the text box against the page edges or center; they do not change paragraph justification. Supported text also offers Helvetica, Times and Courier, with Bold (Command-B) and Italic (Command-I). Imported embedded fonts keep their existing glyphs for text, size and color edits; choose one of the standard families explicitly to change their family or traits. Select characters while typing to format just those characters. With no character selection, the controls set the style for subsequent typing; with the whole box selected, they format the entire box. Mixed selections are identified in the panel. These changes appear on the page before you commit. Use the Text properties button beside Find to show or hide the panel; compact windows open it as a popover. Page navigation and zoom stay in the bottom bar. The left navigation tabs switch between pages, comments and forms; its More menu opens the other panels.

To use an eligible licensed font, open the **Fonts** panel from the navigation More menu and choose **Get “font name” from Google Fonts…** for a missing font. Review the full license in the install dialog; installation records your acceptance. The font then appears under **Licensed fonts installed in this app** in the paragraph’s **Font family** menu. sPDF embeds an eligible TrueType subset for the selected text and refuses missing characters or font files whose embedding rights do not permit it. Fonts installed outside this flow remain render-only, and commercially licensed fonts are not downloaded. Changing the font can reflow the paragraph; review the page before committing. Tools > Text inserts bidirectional Hebrew/Arabic/Devanagari paragraphs (bounded UAX #9, whole-program shaped font, logical copy/search text) or horizontal/vertical CJK text with kinsoku wrapping and Identity-V columns; unsupported scripts, explicit bidi controls and non-CJK vertical input refuse with reasons. Variable fonts use their file’s static default instance; non-default named/coordinate instances and CFF2 refuse with explicit reasons, and the transform profile (horizontal, bounded synthetic-italic shear, pure rotation with uniform scale) refuses unsupported composed transforms instead of approximating them.

Supported multi-line paragraphs select as one object. Type to wrap within the paragraph width; drag the handle on its right edge or change **Width** in Text properties to reflow the words. Return inserts a line break in a paragraph. Saved paragraph lines use the native editor’s actual positions. sPDF also retains its authored box width, soft wrapping and explicit paragraph breaks when reopening, including mixed standard and supported embedded-font spans. Formatting has native Undo/Redo while typing; the complete committed edit is one document Undo. Nearby short labels and uncertain paragraph boundaries remain separate blocks. Visible bullet markers and simple numbered prefixes keep adjacent list items separate, while supported wrapped body lines remain one paragraph. Existing bullet/number glyphs are preserved; this does not provide automatic numbering, list indentation or movement of separately painted markers.

**Done** or Command-Return commits the selected block. Return commits while typing in a single existing line. Escape discards its pending changes. Cut, Copy and Paste use the standard Command-X/C/V shortcuts while typing. Pasted text adopts the current text style. Save commits pending text before writing; closing with changed text prompts to save. Command-Z first undoes typing while the caret is active; committed text and movement use document Undo/Redo. Zooming, scrolling and resizing keep the editor attached to the page.

Paragraph editing supports regular left-aligned horizontal text on unrotated pages when the native wrapping matches the source. It follows separate columns and preserves the source baseline spacing, mixed styles, supported embedded TrueType and simple Type 1C CFF fonts, horizontal Identity-H subsets, character/word spacing and bounded text-array adjustments. Existing font programs and their glyph codes are reused. Visible word-sized positioning gaps can become editable spaces while retaining the original glyph positions; ambiguous letter tracking stays unchanged. A subset can only supply the glyphs it contains; unavailable characters are refused before insertion, and another font can be chosen explicitly. The imported-font path currently covers Latin, Greek and Cyrillic without combining or contextual shaping. Supported embedded-font text inside a single rectangular clipping area can also be edited when all source glyphs are visible. Its original boundary stays fixed and appears as a dashed outline; text that crosses it shows an inline warning and must be brought back inside before committing. Different clipping areas are kept separate. Arbitrary clipping paths, partly hidden source text, vertical/bidirectional text, complex scripts, unsupported CFF encodings, rotated/skewed or nonuniformly transformed text and uncertain paragraph boundaries remain restricted. Uniform source scaling is converted to page points. Paragraphs do not flow onto other pages or move surrounding objects. The standard font controls refuse characters they cannot represent; they do not embed arbitrary system fonts. Reflow Paragraph remains available within its separate font and region limits. Image-only scans need OCR before text can be selected; complex fonts may remain read-only.

Switch back with **Select** (Control-Command-1). In Select mode, dragging a graphic only selects it and never dirties the document.

Click **Images** (Control-Command-4), then **Insert Image…** to place a raster image in the center of the current page. PNG transparency is retained as a soft mask, so transparent pixels reveal the page content beneath them; it is not flattened over white. Drag an inserted image to move it; drag its handles to resize it, holding Shift on a corner to keep proportions. The selected image content is previewed at the proposed position and size, and Escape restores the original. Shift-click or drag a selection rectangle to select several added objects, which resize together with their spacing preserved. Image properties offers X/Y, width/height with **Keep proportions**, page alignment, Rotate 90° and Delete Selection. Numeric image changes apply on Return or when leaving the field; Save commits the active numeric field before writing. With the image selected on the canvas, arrow keys move one point, or ten with Shift. Delete removes added objects in one undoable edit. Escape cancels an active drag; otherwise it clears the selection. Move, resize and Delete are enabled only in Images mode. Use the Image properties button beside Find to show the panel or its compact-window popover.

Supported images already present in the PDF can also be selected and dragged or resized when their draw has an isolatable enclosing transform: direct axis-aligned placements keep their established commands, and nested reusable-form placements are edited copy-on-write (the enclosing form is copied, only the target draw is repointed) with the page transform and clipping preserved. Rotated or skewed canvas handles refuse with a specific reason; the image context menu still offers rotate, flip, scale and replace. Objects → **Edit Image in External Editor…** exports the selected instance with honest provenance (original encoded bytes, stored samples, or an explicitly lossy rendered reconstruction), opens it in a chosen editor, and reimports a returned file only after a preview with mask and aspect policies; the placement box and sibling instances of the same image stay untouched. Shared image objects and unsupported content produce explicit choices or refusal reasons. Objects → **Edit Vector Object…** previews style and transform edits on one ordinary page-level path and refuses gradient shadings, tiling patterns, form XObjects/images, inline images and stale selections without changing content. Edit > Arrange Objects… aligns, distributes, reorders paint order and groups/ungroups the declared page-object profile in one undoable step.

## Annotate, fill forms, and organize pages

File → **Create PDF → From Clipboard, Scanner or Images…** builds a PDF from ordered images, pasted text/images or a documented Image Capture / Print & Scan handoff, with page size, orientation, margins and background options.

Tools → **Review Reports…** exports a printable review summary (page context, numbered comment anchors, reply threads and filters) or, while a comparison is open, a portable comparison report (chosen options, page mapping, change entries with page-space bounds and region images, uncertainty records). Both are local files that never modify the document; larger sets are bounded and refused rather than written partially.

Tools → **Compare With…** opens the comparison workspace with scope presets (content, content and formatting, everything, scans with generated OCR) and channel toggles. Repeated-page groups are audited with warnings; **Use Suggested Pairing** pairs identical pages in document order so reordered or duplicated pages do not cascade into bogus changes, and manual mapping pickers can override any pair with validation. Scan and complex-layout comparisons combine existing text layers with local raster evidence: scan noise is separated from meaningful pixel change, rendering-only differences are not reported as content changes, and missing text extraction is never shown as proof of equality — uncertain pairs are recorded explicitly in the exported report.

Click **Comments** for Highlight, Add Note and Draw controls. The comments sidebar supports navigation, replies, and review state. The Edit and Annotate menus retain advanced annotation commands and drawn signatures. Common form fields can be filled in the page or Forms sidebar; press Return to commit a text value. Form properties and authoring commands are available in the Form menu. Field Rules and Portability… lists declarative sPDF sum/format rules and imported actions (never executed), recalculates static results and can freeze values plus appearances in one undoable step; Rich Text Field Editor… edits bold/italic/size/colour runs with bounded RTF, inherited properties and embedded appearance fonts, refusing unsupported fonts or glyphs. Form > Collect Form Responses… reads completed PDFs and FDF/XFDF/JSON data into one review table (present/empty/missing cells, name/kind conflicts, duplicate submissions) and exports CSV or XLSX without modifying the sources; Form > Validate Form / Accessibility… reports required-field errors with labels/focus targets and screen-reader announcements, validates max length/invalid choices, identifies imported actions as never executed, previews read-only declared show/hide rules and resets defaults in one Undo; Form > Qualify Lifecycle… runs a read-only fill → page operations → save → sign/flatten/export matrix on copies; Form Save Validation… discloses what was validated at save time. Form > Validate Form / Accessibility… reports required-field errors with labels, focus targets and screen-reader announcements, validates max length/invalid choices, identifies imported actions as never executed, previews read-only declared show/hide rules and resets defaults in one Undo; Form > Qualify Lifecycle… runs a read-only fill -> page operations -> save -> sign/flatten/export matrix on copies and distinguishes passed/failed/not-exercised results without changing the document; Form Save Validation… discloses what was validated at save time.

Click **Pages** for the thumbnail organizer (drag block reorder, click/⌘/⇧ selection, range field, zoom, page labels/rotation and one-undo batch move/rotate/duplicate/delete/extract), Insert Blank Page and Rotate Right. The organizer also hosts **Replace Pages**, which previews exactly which destination annotations, links, labels and form fields survive; its retention matrix is shown before applying and source fields follow the chosen rename/refuse policy. The Page menu includes importing, reordering, rotation and deletion. Operations that would damage references are refused or require a supported resolution.

Page → Page Marks adds headers, footers, page numbers, watermarks and Bates numbering with a preview, page list, font, size, opacity, angle, color and margin. An applied mark set is listed in the same dialog and can be edited in place: the previous paint is replaced instead of stacking a second mark, other page content and other mark sets stay intact, and the change is one undo step. **Verify the applied mark sets** shows the text each set actually paints and flags a missing, changed or duplicated mark. Sets saved by an older version, or authored with an embedded custom font, can be verified and removed but not edited in place. Page → Remove Page Mark removes one set as a unit.

Page → **Bates Numbering (Batch)…** numbers a set of PDF files without opening them. Choose the files, order them with Move Up/Move Down, set the prefix, suffix, start number, digit width, placement, margin, font and size, and choose whether the sequence continues across files or restarts for each one. Leading pages and a page list such as `1, 3-5` can be excluded; excluded pages receive no mark and do not consume a number. Each input file is written as an order-prefixed `-bates.pdf` copy through the verified writer, and the folder receives `bates-mapping.csv` and `bates-mapping.json` listing the file-to-sequence mapping and verification result. Encrypted or digitally signed inputs are skipped and reported. A number wider than the requested digit width is kept in full and disclosed rather than cut.

## OCR and exports

OCR in the Annotate menu uses on-device recognition to add searchable text to scans. **Clean Up Scan…** previews deskew, orientation, crop, contrast and background cleanup per page and applies a selective, recoverable replacement; **Reconstruct Scanned Text…** replaces one reviewed word's pixels with the sampled background and adds a visible, searchable, editable text run (complex/colour backgrounds, non-Latin text and ambiguous regions refuse). Annotate > Recognize Mixed Pages… adds bounded searchable text only inside detected scan regions of mixed scanned/digital pages, avoids duplicating selectable digital text and can replace the generated layer without restoring redaction-removed content. Annotate > OCR Files… runs the multi-file OCR job queue with naming templates, cancellation, file-level resume and a per-file JSON report. Tools → Review Tables shows detected cells before CSV or XLSX export. File → **Export Selection / Range…** exports only the chosen scope in text/HTML/RTF/DOCX/tables with an explicit editable-versus-appearance choice and fidelity statement; **Conversion Job Center…** batches conversions with reusable profiles, previewed names/refusals, progress/cancellation and per-file fidelity reports that never overwrite inputs. File → **Create PDF from Source Document…** uses approved handoffs only (local native application for Office/RTF sources, user-directed browser print for HTML, bounded plain-text import) with no embedded web view, upload or bundled converter. Tools hosts **Portfolios…** (browse/extract/add/replace portfolio components in one undoable document command, create a new portfolio derivative) and **Recipe Portability…** plus Import/Export Recipe… (versioned declarative recipe JSON with v0 migration warnings, compatibility report before applying, no code or network execution). Tools → **Automation…** exposes the declared automation profile shared by the CLI/Shortcuts/AppleScript with watched-folder workflows (explicit folders and recipes, settled-arrival detection, exactly-once state, loop prevention, visible failures); **Legacy Compatibility Decisions…** reports document JavaScript/XFA handling (never executed) with explicit removal/flatten copy actions. File → Export groups text, page images, HTML, DOCX, table, attachment, printed PDF and PowerPoint (PPTX) exports; the PPTX action writes the deck plus markdown/JSON editability reports and uses a clearly labelled raster fallback for content outside the reconstructible profile, while table review exports reviewed rows/spans/headers and continuation folding to CSV/XLSX with a review report. [Exports](Exports.md) explains their fidelity limits. Accessibility > Structure and Reading Order… edits the tag tree (create/delete/group/split/reparent, ActualText, language, artifact controls) and reorders a page's reading order independently of paint; Accessibility > Accessible Reading… shows the structure-derived reading model, reflowed text, VoiceOver navigation script, high-contrast findings and tag-preservation verification; Accessibility > Assisted Tagging… reviews heading/paragraph/multicolumn/list/figure/caption/header-footer suggestions, lets you accept/reject/correct them, reports untagged content descriptively (never as a conformance score) and applies accepted suggestions in one Undo; Accessibility > Accessible Tables and Forms… shows table header scopes, /Headers associations, spans and summary plus form labels/tab order and copies the screen-reader-shaped transcript. Accessibility > Accessibility Report… links findings to affected objects and remediation tools, distinguishes automatic from manual checks, reruns only selected rules and states an explicit PDF/UA-1 profile whose pass requires a real independent validator plus all human checks (unavailable validation is never a pass); Tools > DOCX Reconstruction Qualification… scores text completeness, editability, structure and rendered layout separately per document class. Security > Signing Identities… lists Keychain/Secure Enclave/hardware-token/PKCS#12 sources and imports certificates; certificate-only imports cannot sign. Security Presets… offers built-in and custom AES-256 permission presets, Document Security Policy… reports the effective operation matrix, and Change Password / Permissions… / Remove Protection… are verified full rewrites. Tools > Security also hosts Signature Evidence… (read-only trust/timestamp/revocation evidence with the offline trust model disclosed) and Signature Network Preferences… (network disabled by default; enabled https endpoints are allow-listed and only used for explicit actions). Visible certificate signatures, hidden certificate signatures and visible graphical signature marks are presented distinctly; Sign Hidden Certificate… authors an invisible Hidden+NoView field and never a visible appearance. Tools > Security also hosts Certify Document… (P1-P3 DocMDP), Certification and Field Locks… (permissions, locks from /Lock and /Reference, later changes) and Signing Workflows and Limits… (documented review/approval/publish personas with per-signer allowed changes). Certification authoring only applies as the first signature of an unsigned, unencrypted document and refuses an existing DocMDP; other signers' later edits are detected, not prevented.

## Save and recover

Save writes a verified result and preserves original bytes for an untouched document. Edited saves use an incremental revision where eligible, with a verified rewrite when necessary. Protected documents retain their protection policy.

Redaction and sanitization require a separate derivative that removes old revisions. Do not treat a covering annotation or ordinary Save as secure removal. Preserve a backup before an unfamiliar or destructive transformation.

Tools → Security → **Redaction Marks…** opens the review panel. Stage marks from the current selection, the current page or a drawn rectangle; staged marks are listed as pending and change nothing until **Apply**. **Search and Redact** finds literal words, phrases, user patterns or reusable term sets, shows each hit with page/context and a hidden/OCR flag, and lets you review which hits to mark. Applying marks removes the reviewed text or regions in one atomic transaction with one Undo step and forces a secure full rewrite on save; the save barrier warns if pending marks would otherwise be saved unapplied. Hidden text can be excluded (with the policy disclosed) or refused, and text over a scan is removable only by removing the whole intersecting raster draw, which is disclosed before applying. Tools > Security > **Sanitize Hidden Data…** reviews every retained-data category (metadata, comments, links, form values, attachments, actions, optional-content layers, alternate text, OCR layers, thumbnails, /ID, unreachable objects and earlier revisions), applies a selective policy with an attachment allow-list and writes a NEW verified copy that is re-parsed and re-inspected against the policy and optional seed probes; uninspectable retention fails verification instead of implying removal, and the source document is never mutated.

Tools > Print Production also hosts Print Production Workspace… (prepress spot/ink inventory and remap, hairline checks, production marks, raster flattening previews and advanced print plans for N-up/booklet/poster/comments/mixed sizes/duplex). Tools hosts Measurements… (calibrated units/1:N or /Measure scales, distance/perimeter/area, geospatial inspection and round-tripping measurement annotations) and Layers… (layer naming/defaults/order, screen/print/view visibility, marked-content membership, definition import). Searchable discovery, presets, recent files and declared large-document budgets live under Tools (Find a Tool…, Large Document Budget…) and Accessibility (UX Qualification…); hosted review/remote signing/cloud/enterprise services/other platforms/AI/linked reflow are explicit product-scope exclusions recorded in the private decision documents. Tools > Print Production hosts **Preflight and PDF/X Export…** (read-only configurable checks, exact staged fixup previews, declared PDF/X-4 and PDF/X-1a:2003 subsets validated independently with qpdf-JSON and saved-byte verification), **Archival Conversion (PDF/A)…** (declared PDF/A-1b/A-2b/A-3b profiles where output bytes are published only after a compliant veraPDF verdict), **Color-Managed Conversion…** (public CoreGraphics color management with rendering intents and explicit image refusals), **Separation & Overprint Preview…** (owned declared plate/coverage preview with explicit accuracy boundaries) and **Quality Optimization…** (lossless/print/web/smallest presets with measured output and form/OCR/tag/mask/font preservation checks). Linearized/fast-web output is explicitly not supported; ordinary saves stay non-linearized and byte-correct.

Help hosts **sPDF Editor Help…** (⌘?): a quick reference with getting started, keyboard shortcuts, supported workflows and the known exclusions, plus links to the published Daily-Use and Compatibility guides and the issue tracker. Help content is app-and-docs only; it never uploads a document or fetches content in the background. Recovery data stays local. Use sPDF Editor → Check for Updates for a manual release check. Settings contains the automatic-check preference. See [Updates](Updates.md) for installation, unsaved-work handling and guidance for older versions.
